# Campaigns — לוג הקמפיינים הממומנים של מריו

לוג מתמשך של כל קמפיין ממומן: מטרה, תקציב, תוצאות, חוות דעת ופעולות אופטימיזציה.
רשומות חדשות למעלה. **תזכורת:** כל שינוי שכרוך בכסף = אישור ידני של ניר לפני ביצוע.

**פורמט רשומה:**
```markdown

**מטרה:** <Awareness / Traffic / Leads / Sales / Engagement>
**ערוץ:** Facebook / Instagram / שניהם
**תקציב:** <יומי/כולל> | **תקופה:** <תאריכים>
**תוצאות:** CTR: __ | CPM: __ | CPC: __ | CPL: __ | ROAS: __ | Frequency: __
**חוות דעת:** <Hook / קהל / קריאייטיב / הצעה / משפך — תמצית>
**פעולת אופטימיזציה:** <מה הומלץ>
**סטטוס אישור:** ⏳ ממתין / ✅ אושר ובוצע / ❌ נדחה
---
```

## 2026-07-12 | קמפיין גיוס v2 — לידים (גן ברל'ה)
**רקע:** קמפיין ה-Engagement v1 הביא 7 שיחות אך ~כולן לא רלוונטיות (לא דוברות עברית שפת אם).
הלקוח ביקש לעקוף Employment + להחריג יישובים ערביים — **סורב (מדיניות מטא + חוק שוויון
הזדמנויות = הדרה על רקע לאום; סיכון השבתת חשבון + חשיפה משפטית לרועי).** הפתרון הלגיטימי:
קמפיין לידים, **מסומן Employment**, בלי החרגות גיאוגרפיות — הסינון קורה **בטופס** לפי דרישות
תפקיד אמיתיות (עברית שפת אם + הכשרה).
**מטרה:** Leads → טופס מיידי (Instant Form), סוג "כוונה גבוהה" (Higher Intent).
**4 שאלות סינון (בחירה, לא טקסט חופשי):**
1. רמת עברית: שפת אם / שוטפת / בינונית / בסיסית ← הקריטית, רועי מסנן לפי "שפת אם" בלבד.
2. הכשרה: גננת מוסמכת / סטאז'רית / סייעת+ניסיון / אין ניסיון (מוסמכת+סטאז'רית = חיובי).
3. זמינות: מיידית / בתוך חודש / 2-3 חודשים / שנה הבאה.
4. משרה מלאה (4 ימים): כן / רק חלקית.
Intro חוזר על הדרישה (עברית שפת אם + משרה מלאה). מסך סיום עם לינק וואטסאפ.
**טופס שנבנה (Instant Form, "כוונה גבוהה", ידני):** 3 שאלות בחירה (עברית / הכשרה / עוד אחת)
+ שאלה פתוחה ("ערכים חינוכיים / למה מונטסורי") + טלפון חובה. **לוגיקה מותנית:** עברית שפת אם
או שוטפת → ממשיכה; עברית טובה/בסיסית → סגירת טופס (E2 "לא מתאים"). מסך E1 (עברה) = כותרת
"קיבלנו אותך תודה" + כפתור וואטסאפ (wa.me/972505682000). מסך E2 (נחסמה) = פרידה מנומסת,
כפתור לאתר הגן (לא לפרופיל!). כפתור CTA: "להגיש מועמדות". תקציב ₪35/יום.
**קופי:** של רועי + בלוק "מה חשוב שתדעי" (עברית שפת אם + משרה מלאה + אהבה לגיל הרך).
כותרות קרוסלה בקו לבבי/שקט (לא "שטות"). ⚠️ הסינון האמיתי לעברית = שיחת טלפון של רועי
(טופס/שאלה פתוחה חשופים ל-AI). **החלטה: לכבות את קמפיין v1 (Engagement) ולרכז הכל ב-v2.**
**סטטוס:** הועלה 12/07 בבדיקת מטא. פתוח: לחבר אוטומציה שתשלח כל ליד לוואטסאפ של רועי (אמציה);
רועי מוצא לידים כרגע ב"מרכז הלידים" של הדף.
