# reference — חומרי עזר של איתי

התיקייה הזאת מחזיקה חומר גלם שנשלף מהמציאות, בניגוד ל-`blueprints/` שמחזיקה תבניות
שנכתבו. מה שנכנס לכאן:

- **סכימות שנשלפו מבייסים אמיתיים** (`niro-bases-YYYY-MM-DD.md`), פלט של סריקת קריאה
  דרך ה-MCP. זה מקור האמת לתיעוד המערכות הקיימות.
- **יצואי CSV** של טבלאות, כשצריך לנתח דאטה או לתכנן מיגרציה.
- **צילומי מסך של Interfaces** ותצוגות מוצלחות, כהשראה למערכת הבאה.
- **גיליונות של לקוחות** שמהם בונים מיגרציה לשיטס או ל-Airtable.
- **תיעוד רשמי** שהורד או תומצת, כשהוא ארוך מכדי להיכנס ל-Memory.

התיקייה נולדת ריקה ומתמלאת תוך כדי עבודה. מה שמאומת ושימושי לאורך זמן עובר
ל-`itai-crm/Memory/`, כי זה מה שנקרא לפני כל משימה. reference הוא ארכיון, לא זיכרון.
