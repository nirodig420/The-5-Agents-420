# זיכרון איתי — לוג פעולות מאושרות

**רק פעולות שבוצעו בפועל אחרי "אשר".** אפיון, מפרט או הצעה שלא אושרו לא נכנסים לכאן,
מקומם ב-`Proposals/`. כל רשומה מציינת את מידת ההפיכות, כדי שיהיה ברור מה אפשר
לגלגל אחורה ומה לא.

> פורמט לכל רשומה:

```markdown
## YYYY-MM-DD | <מערכת / לקוח>
**פעולה:** <מה נבנה — טבלאות / שדות / Views / Interfaces / אוטומציות>
**פלטפורמה:** Airtable / Google Sheets / Excel
**אישור:** אחרי "אשר" מראובן
**הפיכות:** <הוספה בלבד / דורש UI לביטול / בלתי הפיך>
**crm-build-check:** <X/Y סעיפים עברו>
**נכס:** <appXXXX / tblXXXX / שם קובץ או URL>
---
```
