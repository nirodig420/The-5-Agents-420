**קריאה 1, אחרי שם ומייל** (הטלפון כבר ידוע מוואטסאפ):
```json
{ "action": "lead", "name": "{{שם}}", "phone": "{{טלפון}}", "email": "{{מייל}}" }
```
מחזירה מזהה רשומה (`recXXXX`), שנשמר ב-Custom Field בשם `lead_id`.

**קריאה 2, בסוף האפיון:**
```json

  "urgency": "{{דחיפות}}", "budget_text": "{{תקציב}}" }
```

**הערה קריטית:** ערך `urgency` נשלח כמילה מוכנה ("רותח" / "רגיל" / "לא נמסר תקציב"), בדיוק כמו בווידג'ט. Make לא מחשב כלום. זה הפתרון לבאג שדה המטבע שעלה כבר פעם אחת, והוא מתועד בסקיל `make-scenario-check`.
