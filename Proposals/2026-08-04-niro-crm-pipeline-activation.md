## שלב 0 — שלוש תצוגות. אפס שינוי סכימה, אפס כתיבה

> **למה ידני:** ל-API של Airtable אין `create_view`. אין דרך אחרת, בכל רמת הרשאה.

### View 1 — `🎯 פייפליין` (Kanban). זה העיקר

1. בטבלת `לידים`, בסרגל השמאלי, **`+ Create new...`** → **`Kanban`**.
2. Airtable ישאל **"Stack by"**. בחר את השדה **`שלב עסקה`**.
   *(אם הוא לא מופיע ברשימה, זה אומר שבחרת טבלה אחרת. Kanban מציג רק שדות `singleSelect`.)*
3. קרא לו **`🎯 פייפליין`** (דאבל-קליק על השם).
4. **בלי פילטר.** יש 6 רשומות, כולן צריכות להיות מולך.
5. **`Customize cards`** (או `Fields` בסרגל העליון): השאר גלויים רק
   `שם מלא` · `טלפון ` · `תקציב` · `חבילה` · `דחיפות`.
6. תראה את כל 6 הרשומות בעמודה **`Uncategorized`**. **זו רשימת העבודה שלך.**
   גרור כל אחת לעמודה הנכונה. זה ימלא את `שלב עסקה` לראשונה.
7. אחרי שגררת: **`...` ליד שם ה-View → `Lock view`.**

### View 2 — `📥 חדשים לטיפול` (Grid)

1. **`+ Create new...`** → **`Grid`**. שם: **`📥 חדשים לטיפול`**.
2. **`Filter`** → `+ Add condition`:
   `Where` **`שלב עסקה`** `is` **`ליד חדש`**
   `+ Add condition` → שנה את המילה `Where` ל-**`Or`** → **`שלב עסקה`** `is empty`
3. **`Sort`** → **`מתי נוצר`** → **`9 → 1`** (החדש למעלה).
4. **`Hide fields`** → כבה הכל, ואז הדלק רק:
   `שם מלא` · `טלפון ` · `אימייל` · `איך אפשר לעזור?` · `תקציב` · `מקור` · `דחיפות` · `מתי נוצר`.
5. **`Lock view`**.

> ⚠️ בשלב 4, שדה הטלפון מופיע ברשימה כ-**`טלפון `** עם **רווח בסוף**. זה מכוון ואסור
> לתקן: ארבעה תרחישי Make ממפים אליו בדיוק ככה.

### View 3 — `🔥 רותחים` (Grid)

1. **`+ Create new...`** → **`Grid`**. שם: **`🔥 רותחים`**.
2. **`Filter`**: `Where` **`דחיפות`** `is` **`רותח`**.
3. **`Sort`**: **`תקציב`** → **`9 → 1`**.
4. **`Lock view`**.

### ✅ בדיקה אחרי הבנייה
- שלוש התצוגות קיימות ונעולות (מנעול קטן ליד השם).
- ב-Kanban אין רשומות שנשארו ב-`Uncategorized`.
- שתי התצוגות הישנות (`לקוחות`, `לקוחות משלמים`) **לא נגענו בהן**.

## שלב 1 — אוטומציה. ממתין לאישור נפרד

**טריגר:** `When record created` בטבלת `לידים` → **פעולה:** `Update record`,
`שלב עסקה` = `ליד חדש`.

זה מה שהופך את השדה לממלא-את-עצמו. הטריגר הוא יצירה בלבד, ולכן **הרשומות הקיימות לא
מושפעות**. משהו משתבש, מכבים, ואפס נתונים נפגעים. **את זו אני יכול לבנות דרך ה-API**
(`create_automation`) אחרי אישור.

## שלב 2 — שני שדות מדידה. רק אחרי שבוע של הרצה

| שדה | type | הגדרה |
|---|---|---|
| `שלב עודכן` | `lastModifiedTime` | מוגבל **רק** לשדה `שלב עסקה` |
| `ימים בשלב` | `formula` | `DATETIME_DIFF(NOW(), {שלב עודכן}, 'days')` ⛔ מחושב |

ואז View רביעי: `⏰ תקועים` (`ימים בשלב` > 14, ו`שלב עסקה` לא `נסגר - הקמה`/`לא רלוונטי`).

## ❌ מה לא נוגעים, ולמה

- **שדה `סטטוס`** (`multipleSelects`: רלוונטי/מתנדנד/לא רלוונטי). חופף ל-`שלב עסקה`,
  אבל שינוי טיפוס בלתי אפשרי דרך API ו-rename שובר את Make. **מפסיקים להשתמש, לא מוחקים.**
- **שדה `לקוח משלם`** (checkbox). חופף ל-`נסגר - הקמה` / `ריטיינר פעיל`. אותו טיפול.
- **שדה `"טלפון "`** עם הרווח הסופי. ארבעה תרחישים ממפים אליו.
- **שדה `מקור`** (`multilineText`, ולכן לא ניתן לקבץ לפי מקור ליד). כאב אמיתי, אבל
  התיקון דורש שדה חדש **ומיפוי מחדש אצל אמציה**. הצעה נפרדת.
- **שש הרשומות הקיימות.** אין כתיבה אליהן בשום שלב. מילוי `שלב עסקה` נעשה **על ידך,
  בגרירה ידנית ב-Kanban**, לא בקריאת API.
