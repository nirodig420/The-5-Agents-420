## תוכנית בדיקה (אחרי היצירה, לפני ON, באישור ניר)

1. רשומת דמה: "🧪 בדיקה חימום - למחוק", טלפון = המספר של ניר (בתוך שלוש הצ'אטים
   המותרות), שלב עסקה="ליד חדש", תאריך יצירה אחרי תאריך ההשקה שבנוסחה.
2. Run once → מצופה: וואטסאפ יום 0 אצל ניר, וברשומה שלב=1 + שליחה אחרונה + תיעוד.
3. הרצה שנייה מיד → מצופה: כלום (שלב=1 והיום הבא עוד לא הגיע). זו בדיקת האנטי-כפילות.
4. הזזת "חימום - שליחה אחרונה" יומיים אחורה ידנית → Run once → הודעת יום 1 מה-AI.
   בודקים: עברית, אורך, שם פרטי, CTA אחד, בלי המצאות. חוזרים על התרגיל לימים 3 ו-5.
5. בדיקת עצירה: מחזירים את הרשומה לשלב=1, משנים "שלב עסקה" ל"שיחת אבחון נקבעה"
   → Run once → מצופה: כלום. זו דרישה 4 עובדת.
6. מוחקים את רשומת הדמה. רק אז, ובאישור מפורש של ניר: ON + אימות isActive
   ו-scheduling ב-scenarios_get.
