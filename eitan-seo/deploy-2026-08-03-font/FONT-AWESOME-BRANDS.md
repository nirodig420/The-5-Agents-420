## צעד 1: הוסף כלל CSS אחד

בתוך בלוק ה-`<style>`, מומלץ מיד אחרי כלל הכותרות של Frank Ruhl:

```css
        .ni-ico {
            width: 1em; height: 1em;
            display: inline-block;
            vertical-align: -0.125em;
            fill: currentColor;
        }
```

**מה זה עושה:** גורם ל-SVG להתנהג בדיוק כמו אות בפונט אייקונים.
`1em` אומר "קח את הגודל מגודל הטקסט סביבך", ו-`fill: currentColor` אומר
"קח את הצבע מהצבע של הטקסט סביבך".

**המשמעות המעשית: כל ה-CSS הקיים שלך ממשיך לעבוד בדיוק כמו קודם.**
אם כפתור הוואטסאפ היה ירוק ובגודל 20px, האייקון יישאר ירוק ובגודל 20px,
בלי שתשנה שום כלל צבע או גודל.

הערך `-0.125em` הוא בדיוק מה ש-Font Awesome משתמשת בו כדי ליישר אייקון
לקו הבסיס של הטקסט. זה מונע קפיצה של האייקון למעלה או למטה.

## צעד 4: איך לוודא שזה עבד

### הבדיקה הראשונה: שאין יותר אף `fab`

בעורך, `Ctrl+F` וחפש:

```
fab fa-
```

**חייב להחזיר אפס תוצאות בשני הקבצים.** אם נשאר אפילו אחד,
הדפדפן ימשיך להוריד את כל 104KB, וכל העבודה הייתה לשווא.

### הבדיקה השנייה: שהקובץ באמת הפסיק לרדת

1. פתח את האתר בחלון גלישה בסתר.
2. לחץ `F12` ← לשונית **Network** ← סנן לפי **Font**.
3. רענן עם `Ctrl+F5`.
4. **`fa-brands-400.woff2` לא אמור להופיע ברשימה בכלל.**
5. `fa-solid-900.woff2` **כן** אמור להופיע. הוא נשאר, וזה תקין.

### הבדיקה השלישית: ויזואלית

ארבעת האייקונים צריכים להיראות **זהים לחלוטין** למה שהיה:

- פייסבוק ואינסטגרם בכותרת העליונה, באותו גודל ובאותו צבע
- אייקון הוואטסאפ בכפתור הירוק, מיושר לטקסט לידו
- אייקון הוואטסאפ מתחת לטופס

**אם אייקון קפץ למעלה או למטה ביחס לטקסט:** הכלל `.ni-ico` לא נוסף,
או שנוסף אחרי שהתגית כבר בשימוש. בדוק שהוא בתוך בלוק ה-`<style>`.

**אם אייקון יצא שחור במקום בצבע הנכון:** חסר `fill="currentColor"` בתגית.

## למה SVG מוטמע ולא קובץ SVG נפרד

הטמעה ישירה בקוד לא יוצרת **שום בקשת רשת נוספת**. קובץ SVG נפרד היה חוסך
את ה-104KB אבל מוסיף 4 בקשות רשת חדשות, וזה מחליף בעיה אחת באחרת.

הארבעה יחד מוסיפים כ-**3.4KB** לקוד ה-HTML, שנדחס בגזיפ לפחות מקילובייט.
**המאזן: מינוס 104KB, פלוס פחות מקילובייט.**

## מה שנשאר לפעם הבאה: חיתוך `fa-solid-900.woff2`

הקובץ `fa-solid-900.woff2` שוקל **126,828 בייט ומשרת 52 אייקונים** מתוך אלפים.
חיתוך (subsetting) שלו רק ל-52 האייקונים שבשימוש יוריד אותו לכ-10KB,
כלומר **חיסכון נוסף של כ-115KB**.

**למה לא עשיתי את זה:** הפעולה דורשת את הכלי `pyftsubset` מחבילת `fonttools`.
בדקתי היום את המכונה הזאת: **אין עליה Python תקין**, רק קיצור דרך של חנות
Windows שלא מריץ קוד. **לא ניסיתי לעקוף את זה** ולא התקנתי כלום בלי אישור.

**מה נדרש כדי לבצע בעתיד:**

1. להתקין Python מ-`python.org` (לא מחנות Windows).
2. `pip install fonttools brotli`
3. להוריד את `fa-solid-900.woff2` המקורי.
4. להריץ `pyftsubset` עם רשימת 52 קודי הגליפים שבשימוש.
5. להעלות את הקובץ החתוך ולהוסיף `@font-face` מקומי שמצביע עליו.

זו משימה נפרדת עם הכנה משלה. **תגיד לי כשתרצה ואכין הצעה מלאה**, כולל
רשימת 52 קודי האייקונים המדויקים.
