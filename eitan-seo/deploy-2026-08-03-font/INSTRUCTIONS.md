1. נווט ל-`wp-content → themes → hello-elementor`.
2. **קליק ימני** על `front-page.php` ← בחר **Copy** (העתק).

```
front-page.php.bak-2026-08-03
```

**חשוב: הסיומת חייבת להיות `.bak-2026-08-03` ולא `.php`.** ככה וורדפרס
מתעלם ממנו לגמרי והוא רק יושב שם כגיבוי.


## צעד 1: הסרת Figtree ו-Poppins

**מה הבעיה:** בעמוד `/thank-you/` ובעמוד ה-404 נטענות **שתי משפחות פונטים

**ולשתיהן אין בכלל אותיות עבריות.** זה משקל טהור בלי שום תועלת, ודווקא בעמוד

### אפשרות א (מומלצת): ממשק Elementor

1. בתפריט וורדפרס לחץ על **Elementor** ← **Settings**.
2. פתח דף כלשהו ב-Elementor, ואז לחץ על **תפריט ההמבורגר** (שלושה קווים)
   בפינה העליונה של הסרגל הצדדי.
3. בחר **Site Settings** ← **Global Fonts**.
4. תראה רשימה של סגנונות טיפוגרפיה (Primary, Secondary, Text, Accent).
5. פתח כל אחד מהם, ובשדה **Family** (משפחה):
   - אם כתוב שם **Poppins** או **Figtree**, שנה ל-**IBM Plex Sans Hebrew**.
   - אם השדה כבר ריק, **עזוב אותו ריק.** ריק זה הכי טוב.
6. לחץ **Update** (עדכן).

**איך לוודא:** פתח `https://www.nirodigital.co.il/thank-you/`,
לחץ `Ctrl+U` (הצגת מקור), ואז `Ctrl+F` וחפש `Poppins`.
**צריך להיות אפס תוצאות.**

### אפשרות ב (רק אם הממשק לא עובד): קוד

אם הממשק לא נותן להסיר, אפשר לבטל את התור בקוד. זה נכנס ל-`functions.php`
של התבנית או ל-Code Snippet:

```php
add_action( 'wp_enqueue_scripts', function () {
    wp_dequeue_style( 'elementor-gf-poppins' );
    wp_deregister_style( 'elementor-gf-poppins' );
    wp_dequeue_style( 'elementor-gf-figtree' );
    wp_deregister_style( 'elementor-gf-figtree' );
}, 100 );
```

(שני המזהים `elementor-gf-poppins` ו-`elementor-gf-figtree` נלקחו מהקוד החי
של האתר היום, לא מהזיכרון.)

### ⭐ ההמלצה שלי: אפשרות א

**שלוש סיבות:**

1. **היא מתקנת את הסיבה, לא את הסימפטום.** אפשרות ב משאירה את ההגדרה השגויה

2. **היא הפיכה בלחיצה אחת** ולא דורשת נגיעה בקוד בכלל.
3. **אפשרות ב דורשת נגיעה ב-`functions.php`**, וזה קובץ שטעות בו מפילה
   את כל האתר למסך לבן. בשביל שיפור ביצועים בעמוד פנימי, זה סיכון מיותר.

# שיפורים נלווים: אחרי שהאבק שוקע

**אל תעשה אותם באותה העלאה.** תן לפונט להתייצב קודם.

| שיפור | חיסכון | סטטוס |
|---|---|---|
| אייקוני Font Awesome brands ל-SVG | **104KB** | מוכן. ראה `FONT-AWESOME-BRANDS.md` |
| חיתוך `fa-solid-900.woff2` | כ-115KB | **לא ניתן לביצוע כרגע.** ראה למטה |
| אחסון עצמי של הפונטים | חוסך 2 חיבורים חיצוניים | הצעה נפרדת בעתיד |
| מעבר לתבנית בת (child theme) | מונע מחיקת האתר | **מומלץ בחום** |

**למה חיתוך `fa-solid-900.woff2` לא נעשה:** הקובץ שוקל 126KB ומשרת 52 אייקונים
מתוך אלפים. חיתוך שלו היה מוריד אותו לכ-10KB. הפעולה דורשת את הכלי
`pyftsubset` מחבילת `fonttools`, שדורש Python עובד.
**בדקתי היום: אין Python תקין על המכונה הזאת**, רק קיצור דרך של חנות Windows
שלא מריץ כלום. כדי לבצע את זה בעתיד צריך להתקין Python מ-`python.org`
ואז `pip install fonttools brotli`. **לא ניסיתי לעקוף את זה.**

# מה אישרת, ומה זה אומר בפועל

## 1. הנראות אושרה

הסריף בכותרות נשאר כפי שראית בתצוגה המקדימה, בעברית ובאנגלית.
**לא שיניתי שום דבר בעיצוב אחרי שאישרת.**

## 2. משקל 600 יורד

זה שינוי אמיתי, אז שתדע בדיוק מה קרה.

**מה שהיה בתצוגה המקדימה שראית:** IBM Plex ב-400, 600 ו-700.
**מה שיהיה עכשיו:** IBM Plex ב-400 ו-700 בלבד.

ששת המקומות שהיו 600 והופכים 700:

| קובץ | סלקטור | מה זה |
|---|---|---|
| עברית | `.nav-link` | קישורי הניווט בכותרת העליונה |
| עברית | `.diag-opt .opt-text small` | טקסט משנה בכפתורי האבחון |
| עברית | `.claude-sec .eyebrow` | תווית eyebrow בסקשן Claude |
| עברית | `.claude-edge` | פסקת ההדגשה בסקשן Claude |
| אנגלית | `.nav-link` | קישורי הניווט |
| אנגלית | `.diag-opt .opt-text small` | טקסט משנה בכפתורי האבחון |

**האם תראה הבדל?** כמעט לא. הפער בין 600 ל-700 הוא הקטן ביותר בכל סולם
המשקלים, וכל ששת המקומות האלה הם בגדלים של 13px עד 18px.
**הכי מורגש יהיה בקישורי הניווט למעלה, שיהיו טיפה יותר עבים.**

**עדכנתי את `preview-he.html` ו-`preview-en.html` לגרסה הזאת.**
התווית בפינה אומרת עכשיו `AFTER - Frank Ruhl + IBM Plex (400/700)`.
**כדאי לפתוח אותם שוב ולהעיף מבט על הניווט למעלה**, רק כדי לוודא שזה מוצא חן בעיניך.
אם לא, זו החזרה של שורה אחת ואני מחזיר את 600.
